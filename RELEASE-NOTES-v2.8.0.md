# Noise Division v2.8.0

## TRANSPLANT 1.4.0
- INPUT and OUTPUT (bottom centre): the level into and out of TRANSPLANT for the whole song, −24 to +24 dB. Drag, Shift for fine, double-click for 0 dB. BYPASS keeps both, so A/B compares only the EQ.
- The per-section level in MATCH is now called GAIN (it was OUTPUT).
- HEAR ON: Club and Car no longer distort on loud masters (an automatic trim turns the preview down instead), and a new MONO choice folds everything to mono.
