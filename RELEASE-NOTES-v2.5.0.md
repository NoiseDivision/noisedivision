# Noise Division v2.5.0

## TRANSPLANT 1.1.0
- Each section keeps its own MATCH settings: AMOUNT, SMOOTH, RANGE, FROM, TO and OUTPUT. The MATCH drawer shows and changes the section on the display ("SETTINGS FOR DROP 2"), so an intro can get a light touch while the drop gets the full match.
- New COPY TO ALL button: gives every section the settings of the one on the display. Presets set every section.
- Bigger, easier-to-read text in the METERS drawer.
- Projects made with 1.0.0 open as before: every section starts with the settings it had.
